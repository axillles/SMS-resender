# Онбординг: скрины для светлой и тёмной темы

## Как устроено

В Asset Catalog у каждого изображения может быть **несколько вариантов по внешнему виду (Appearance)**. Для онбординга используем варианты **Light** и **Dark** — система сама подставит нужную картинку в зависимости от темы пользователя.

## Шаги в Xcode

### 1. Imageset для каждого шага

Для шагов онбординга нужны imageset’ы с именами:

- `Step1`, `Step2`, `Step3`, `Step4`, `Step5_1`, `Step5_2`, `Step6`, `Step7`, `Step8`, `Step9`, `Step10`

Можно держать их в группе **Onboarding** в левой панели Assets.

### 2. Добавление Light и Dark вариантов

Для каждого imageset (например, Step1):

1. Выбери imageset в каталоге.
2. В инспекторе справа в блоке **Appearances** выбери **Any, Light, Dark** (три квадрата).
3. В слот **Light** перетащи скрин для светлой темы (или нажми и выбери файл).
4. В слот **Dark** перетащи скрин для тёмной темы.

Имена файлов могут быть любыми, например:

- светлая тема: `Step1.png`
- тёмная тема: `Step1-dark.png`

Главное — указать нужный файл в нужном слоте (Light/Dark).

### 3. Формат файлов

- **Формат:** PNG (или JPEG).
- **Размер:** можно в 1x; для ретины Xcode сам предложит 2x/3x при необходимости.
- В `Contents.json` для каждого imageset будет что-то вроде:

```json
"images" : [
  {
    "appearances" : [ { "appearance" : "luminosity", "value" : "dark" } ],
    "filename" : "Step1-dark.png",
    "idiom" : "universal",
    "scale" : "1x"
  },
  {
    "appearances" : [ { "appearance" : "luminosity", "value" : "light" } ],
    "filename" : "Step1.png",
    "idiom" : "universal",
    "scale" : "1x"
  }
]
```

## Как сделать скрины

1. **Светлая тема:** Настройки → Экран и яркость → Светлый. Запусти онбординг, сделай скрины шагов.
2. **Тёмная тема:** Переключи на Тёмный, снова пройди онбординг и сделай скрины тех же шагов.
3. Положи светлые и тёмные файлы в соответствующие imageset’ы в Assets (слоты Light и Dark), как в п. 2 выше.

Код онбординга уже запрашивает картинки по имени (`Step1`, `Step2`, …). `UIImage(named:)` из Asset Catalog автоматически подставляет вариант по текущей теме (Light/Dark), менять код не нужно.
